## 本次交付范围
本阶段基于前两期成果，继续按文档补齐“认证与登录增强 + 文件上传 + 企业认证资料提交”能力，形成更完整的企业入驻和账号安全闭环。

- 退出登录
- 企业认证资料提交
- 企业认证状态查询

### 前端
- 登录页验证码登录
- 登录页找回密码
- 登录页注册验证码发送
- 企业中心认证状态展示
- 营业执照上传
- 企业 Logo 上传
- 企业认证资料提交

## 使用说明
### 1. 启动后端
```bash
cd backend
mvn spring-boot:run
```

### 2. 启动前端
```bash
cd frontend
npm run serve
```

### 3. 本地上传目录
- 默认上传目录：`backend/uploads`
- 访问路径示例：`http://localhost:8084/uploads/xxxxxx.png`

### 4. 开发环境短信验证码
- 当前调试验证码固定为：`123456`
- 发送验证码后前端页面也会显示 `debugCode`

## 当前能力说明
- 企业注册后可在企业中心直接补充认证资料
- 企业上传营业执照和 Logo 后可提交审核
- 审核未通过时可查看驳回原因并重新提交
- 求职者可使用短信验证码登录
- 求职者与企业都可通过短信验证码重置密码

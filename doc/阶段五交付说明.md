## 使用说明
### Redis 与邮件
- 本地运行前可通过 `application.yaml` 或环境变量配置 Redis 与 SMTP
- 未配置邮件服务时，验证码会通过日志模拟发送，便于联调

### 管理员后台
- 进入“轮播图管理”页签后，先上传 `BANNER` 图片，再保存轮播图
- 进入“角色权限”页签后，可直接配置角色与权限集合
- 进入“消息模板”页签后，可修改标题模板、内容模板与发送通道

### 兼容接口
- 平台统计总览现同时支持：
  - `/recruit/api/v1/statistics/platform/overview`
  - `/recruit/api/v1/admin/statistics/overview`

# 校企慧招聘模块阶段二交付说明

## 本次交付范围
本阶段基于一期 MVP，继续按文档完成管理员端与审核流能力，形成“企业提交 -> 管理员审核 -> 消息反馈 -> 前端展示”的二期闭环。

## 交付模块
### 后端模块
- 管理员认证
- 用户管理
- 企业认证审核
- 职位审核
- 公告审核与管理
- 职位分类管理
- 审核日志

### 前端模块
- 管理员登录
- 管理员后台工作台
- 求职者管理页
- 企业管理页
- 职位审核页
- 公告管理页
- 分类管理页
- 审核日志页

## 主要代码位置
### 后端
- 管理员控制器：`backend/src/main/java/main/xiaoqihui/admin/AdminController.java`
- 管理员服务：`backend/src/main/java/main/xiaoqihui/admin/AdminService.java`
- 管理员 Mapper：`backend/src/main/java/main/xiaoqihui/admin/AdminMapper.java`
- 安全配置：`backend/src/main/java/main/xiaoqihui/common/config/SecurityConfig.java`
- 初始化逻辑：`backend/src/main/java/main/xiaoqihui/common/config/DataInitializer.java`
- 二期数据库脚本：`backend/src/main/resources/sql/stage2_admin.sql`

### 前端
- 管理后台：`frontend/src/views/AdminCenterView.vue`
- 登录页：`frontend/src/views/LoginView.vue`
- 路由：`frontend/src/router/index.ts`
- 管理端接口封装：`frontend/src/api/recruit.ts`

## 运行说明
### 1. 启动后端
```bash
cd backend
mvn spring-boot:run
```

### 2. 启动前端
```bash
cd frontend
npm run serve
```

### 3. 默认接口地址
- 前端默认请求地址：`http://localhost:8084/recruit/api/v1`
- 后端默认端口：`8084`

### 4. 默认管理员账号
- 手机号：`18800000000`
- 密码：`Admin@123456`

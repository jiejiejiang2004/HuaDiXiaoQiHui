# 校企慧招聘模块阶段五开发日志

## 阶段目标
- 对照接口文档补齐后台系统管理缺口
- 将认证链路升级为 `JWT + Redis` 双校验
- 引入任务队列处理验证码邮件等异步任务
- 修复企业登录异常与管理员统计 SQL 异常
- 将验证码能力从短信统一切换为邮箱

## 本阶段完成内容
### 1. 认证与会话
- 新增 Redis Token 存储组件：`RedisTokenStore`
- JWT 过滤器改为同时校验 JWT 与 Redis 中的 accessToken
- 管理员登录补充 Redis Token 写入，避免登录成功后访问后台接口被判定失效
- 保留 refreshToken 机制，并支持 Redis 中的 refreshToken 鉴定与注销

### 2. 异步任务与邮件验证码
- 新增异步线程池配置：`AsyncConfig`
- 新增任务队列服务：`TaskQueueService`
- 新增邮件发送服务：`MailSenderService`
- 通用验证码接口从 `/common/sms/send` 切换为 `/common/email/send`
- 求职者验证码登录从 `/user/login/sms` 切换为 `/user/login/email`
- 注册、找回密码、企业注册全部统一为邮箱验证码校验

### 3. 登录与统计问题修复
- 修复企业登录触发的 `IllegalAccessError`
  - 将 `CompanyInfoEntity`、`JobEntity`、`ApplicationEntity` 从聚合文件拆分为独立 `public class`
- 修复管理员统计 SQL 语法错误
  - 移除注解 SQL 中错误写入的 `<![CDATA[<=]]>`
- 平台统计接口补充文档兼容路径：
  - `/recruit/api/v1/admin/statistics/overview`

### 4. 系统管理能力补齐
- 新增轮播图管理接口：
  - `GET/POST/PUT/DELETE /admin/system/banners`
- 新增角色权限管理接口：
  - `GET /admin/system/permissions`
  - `GET/POST/PUT/DELETE /admin/system/roles`
- 新增消息模板管理接口：
  - `GET /admin/system/message/templates`
  - `PUT /admin/system/message/templates/{templateId}`
- 管理员后台前端补充：
  - 轮播图上传与删除
  - 角色权限分配
  - 消息模板在线编辑

### 5. 数据库与初始化
- 新增脚本：`stage5_system_management.sql`
- 新增表：
  - `sys_banner`
  - `sys_role`
  - `sys_permission`
  - `sys_role_permission`
  - `sys_message_template`
- 初始化默认数据：
  - 平台管理员角色
  - 后台权限项
  - 默认消息模板

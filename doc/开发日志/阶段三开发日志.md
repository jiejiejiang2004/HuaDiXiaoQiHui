# 校企慧招聘模块三期开发日志

## 阶段目标
- 补齐短信验证码发送与验证码登录/重置密码链路
- 增加统一文件上传能力
- 完成企业认证资料提交与状态查询
- 将企业中心与登录页调整为更贴近原型和接口文档

## 本阶段完成内容
### 1. 后端通用能力
- 新增字典接口：`/recruit/api/v1/common/dict/{dictType}`
- 新增短信发送接口：`/recruit/api/v1/common/sms/send`
- 新增统一文件上传接口：`/recruit/api/v1/common/file/upload`
- 新增本地上传目录映射：`/uploads/**`

### 2. 后端认证扩展
- 求职者注册改为校验短信验证码
- 企业注册改为校验短信验证码
- 新增求职者验证码登录接口：`/recruit/api/v1/user/login/sms`
- 新增密码重置接口：
  - `/recruit/api/v1/user/password/reset`
  - `/recruit/api/v1/enterprise/password/reset`
- 新增 Token 刷新接口：`/recruit/api/v1/user/token/refresh`
- 新增退出登录接口：`/recruit/api/v1/user/logout`

### 3. 企业认证
- 新增企业认证提交接口：`/recruit/api/v1/enterprise/auth`
- 新增企业认证状态查询接口：`/recruit/api/v1/enterprise/auth/status`
- 新增 `company_auth` 表保存认证资料和审核结果
- 管理员审核企业时同步更新 `company_auth` 审核记录

### 4. 文件上传与存储
- 新增 `sys_file_record` 表
- 支持业务类型：
  - `RESUME`
  - `LICENSE`
  - `LOGO`
  - `AVATAR`
  - `BANNER`
- 支持大小和格式校验

### 5. 前端
- 登录页新增：
  - 求职者验证码登录
  - 注册验证码发送
  - 找回密码弹窗
  - 企业注册验证码发送
- 企业中心新增：
  - 认证状态提示
  - 驳回原因展示
  - 营业执照上传
  - Logo 上传
  - 企业认证资料提交
- 前端新增上传 URL 解析能力，兼容本地 `/uploads/**` 文件访问

## 测试约定

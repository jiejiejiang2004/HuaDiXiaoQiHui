# 校企慧招聘模块二期开发日志

## 阶段目标
- 补齐管理员端核心能力
- 建立企业认证审核、职位审核、公告审核闭环
- 增加职位分类管理与审核日志能力
- 同步补全前端管理后台入口和页面

## 本阶段完成内容
### 1. 后端
- 新增管理员登录接口：`/recruit/api/v1/admin/login`
- 新增求职者管理接口：
  - 查询求职者列表
  - 查询求职者详情
  - 启用/禁用求职者账号
- 新增企业管理接口：
  - 查询企业列表
  - 企业认证审核
  - 启用/禁用企业账号
  - 管理员编辑企业信息
- 新增审核接口：
  - 待审核职位列表
  - 审核职位
  - 待审核公告列表
  - 审核公告
- 新增系统管理接口：
  - 职位分类查询/新增/修改/删除
  - 公告查询/新增/修改/删除
  - 审核日志查询

### 2. 数据库
- 新增脚本：`sql/stage2_admin.sql`
- 扩展表结构：
  - `company_info.auth_remark`
  - `job_position.audit_remark`
- 新增管理表：
  - `job_category`
  - `job_notice`
  - `sys_audit_log`

### 3. 初始化
- 应用启动时自动执行 `mvp_init.sql` 与 `stage2_admin.sql`
- 自动初始化默认管理员账号
- 自动初始化基础职位分类与示例公告

### 4. 前端
- 登录页新增管理员登录页签
- 新增管理员后台页面
- 支持以下界面能力：
  - 求职者管理
  - 企业管理
  - 职位审核
  - 公告管理/审核
  - 分类管理
  - 审核日志查看

## 关键业务调整
- 企业注册后认证状态默认改为 `PENDING`
- 企业发布/编辑职位需认证通过后才可提交
- 企业新建职位默认进入 `PENDING` 待审核状态
- 管理员审核通过后职位变为 `RECRUITING`

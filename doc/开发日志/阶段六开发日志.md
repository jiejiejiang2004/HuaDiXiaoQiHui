# 校企慧招聘模块阶段六开发日志

## 阶段目标
- 再次对照文档，优先补齐导出与下载相关缺口
- 修复管理员后台 `ResizeObserver` 开发环境报错
- 完善 token 失效后的自动续期体验
- 将邮箱验证码与简历导出升级为 HTML 模板驱动

## 本阶段完成内容
### 1. 文档差距复核
- 再次对照 `doc/api.md` 与原型、时序图核查实现状态
- 重点确认本轮优先补齐的缺口为：
  - 报表导出真实下载链路
  - 简历 PDF 导出
  - 邮箱 HTML 模板发送
  - 管理端页面开发环境报错治理

### 2. 报表导出完善
- 统计导出支持 `xlsx/csv`
- 后端真实生成文件并落盘到 `/uploads/reports`
- 通用文件下载接口新增：
  - `GET /recruit/api/v1/common/file/download/{fileId}`
- 前端下载逻辑改为携带鉴权请求下载，不再仅依赖 `window.open`
- 管理员、求职者、企业端导出统计统一改为直接下载文件

### 3. Token 自动续期
- `frontend/src/api/http.ts` 新增基于 `refreshToken` 的自动刷新逻辑
- 当接口返回 `2001` 时，优先尝试刷新 `accessToken` 并自动重放原请求
- 下载二进制文件时同样支持基于 `401/403` 的 token 刷新重试
- 该改动直接解决“导出时报用户未登录或 Token 失效”的高概率问题

### 4. 简历导出 PDF
- 新增 HTML 转 PDF 服务：`HtmlPdfRenderService`
- 新增简历导出接口：
  - `GET /recruit/api/v1/resume/{resumeId}/export/pdf`
  - `GET /recruit/api/v1/enterprise/resumes/{resumeId}/export/pdf`
- 使用 HTML 模板拼装求职者基础信息、求职意向、教育经历、工作经历、技能标签、自我评价
- 前端求职者中心与企业简历查看弹窗均补充“导出简历 PDF”按钮

### 5. 邮箱 HTML 模板
- `MailSenderService` 从纯文本邮件改为 HTML 邮件发送
- 验证码作为参数注入模板
- 邮件未配置 SMTP 时继续保留日志模拟发送，便于联调

### 6. 前端异常治理
- `main.ts` 层面对 `ResizeObserver loop completed with undelivered notifications` 做定向拦截
- 避免 webpack dev overlay 在管理员企业管理、分类管理等表格场景频繁弹错

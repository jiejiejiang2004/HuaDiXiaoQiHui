# 校企慧招聘模块阶段七开发日志

## 阶段目标
- 继续对照 `api.md` 补齐高频需求缺口
- 优先完善消息中心、简历管理、企业职位操作闭环
- 彻底修复管理员各模块进入时的 `ResizeObserver` 开发环境报错
- 同步更新数据库设计、开发日志与交付说明

## 本阶段完成内容
### 1. 前端全局异常治理
- 对 `ResizeObserver` 增加三层兜底：
  - 包装原生 `ResizeObserver` 回调，放入 `requestAnimationFrame`
  - 在捕获阶段拦截对应 `error` 事件并 `preventDefault`
  - 过滤控制台中对应的 `ResizeObserver` 错误输出
- 用于解决管理员进入求职者管理、企业管理、分类管理等表格密集页面时 webpack overlay 弹错问题

### 2. 消息中心补齐
- 新增接口：
  - `GET /recruit/api/v1/messages/{messageId}`
  - `DELETE /recruit/api/v1/messages`
  - `GET /recruit/api/v1/messages/unread/count`
- 消息列表补充未读数与按类型统计
- 前端消息中心补充：
  - 消息详情弹窗
  - 单条删除
  - 未读数展示

### 3. 简历管理补齐
- 新增接口：
  - `DELETE /recruit/api/v1/resume/{resumeId}`
  - `PUT /recruit/api/v1/resume/{resumeId}/default`
  - `PUT /recruit/api/v1/resume/{resumeId}/privacy`
  - `POST /recruit/api/v1/resume/{resumeId}/attachment`
  - `DELETE /recruit/api/v1/resume/{resumeId}/attachment/{attachmentId}`
- 新增 `resume_attachment` 表保存简历附件关联关系
- 简历详情返回补充 `attachmentList`
- 前端求职者中心补充：
  - 设为默认简历
  - 隐私设置切换
  - 简历附件上传、下载、删除

### 4. 企业职位操作补齐
- 新增接口：
  - `PUT /recruit/api/v1/enterprise/jobs/{jobId}/offline`
  - `PUT /recruit/api/v1/enterprise/jobs/{jobId}/refresh`
  - `DELETE /recruit/api/v1/enterprise/jobs/{jobId}`
  - `GET /recruit/api/v1/enterprise/jobs/{jobId}/preview`
  - `GET /recruit/api/v1/enterprise/jobs/{jobId}/share`
- 新增 `enterprise_job_refresh_log` 表记录每日刷新次数
- 刷新逻辑按文档限制为单职位每日最多 3 次
- 企业端职位列表补充预览、刷新、分享、下架、删除操作

# 阶段十交付说明

## 新增能力
- 企业端：
  - 简历收藏 / 取消收藏
  - 收藏夹搜索
  - 批量导出简历
- 平台内部：
  - 站内消息推送接口
  - SSO Token 校验接口
  - 通用邮件发送接口
- 管理端：
  - 简历违规检测 / 清理
  - 操作日志查询

## 验证建议
- 企业账号登录后，验证收藏、搜索、批量导出是否可用。
- 管理员进入求职者详情，验证简历检测与清理按钮。
- 管理员进入操作日志，验证管理动作是否有留痕。
- 模拟业务异常，确认前端不再弹出 `[object Object]`。
- 前端执行 `npm run serve` 时，确认阶段十新增文件不再出现 `prettier` 格式错误。
